# morse-core

Código Morse ITU: codifica/decodifica letras, dígitos e pontuação, com
tokens estritos. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 5 testes, node:test, sem dependências
npm run demo
```
